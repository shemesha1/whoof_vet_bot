# Whoof Vet Bot

Telegram-бот, который после покупки ошейника приглашает покупателя на **бесплатную консультацию ветеринара** и даёт выбрать удобное время.

Покупатель получает персональную ссылку (на странице «Спасибо за заказ», в письме или QR-кодом на вкладыше в коробке) → открывает бота → выбирает день и время → получает подтверждение, напоминания за сутки и за час, ссылку на звонок и после консультации просьбу оценить её. Ветеринары получают уведомления о записях в свой чат, администратор управляет расписанием прямо из Telegram.

## Возможности

- Привязка покупки к Telegram через deep-link `t.me/<бот>?start=<код>` или ввод кода с карточки
- Выбор дня и времени inline-кнопками, защита от двойной записи на одно время
- Перенос и отмена записи
- Напоминания за 24 часа и за 1 час (со ссылкой на видеозвонок)
- Запрос оценки после консультации, алерт врачам при оценке 3 и ниже
- Одно напоминание тем, кто перешёл в бота, но не записался
- Уведомления в чат ветеринаров: новая запись, перенос, отмена, «нет свободных окон»
- Админ-команды: расписание, список записей, ручные приглашения, воронка
- HTTP-вебхук для интернет-магазина: «заказ оплачен» → ссылка на бота
- Скрипты: массовое добавление расписания и генерация кодов с QR для печати

## Быстрый старт (локально, 10 минут)

```bash
# 1. Установить зависимости (нужен Python 3.11+)
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# 2. Настроить
cp .env.example .env               # Windows: copy .env.example .env
# впишите BOT_TOKEN от @BotFather

# 3. Запустить
python -m bot
```

Дальше в Telegram:

1. Отправьте боту `/id`, впишите свой id в `ADMIN_IDS` в `.env` и перезапустите бота.
2. Добавьте окна: `/slots_add 2026-10-12 10:00-18:00 30`
3. Создайте тестовое приглашение: `/invite Тест` и откройте полученную ссылку.

Полная пошаговая инструкция (сервер, Docker, подключение магазина, QR-коды, персональные данные) – в [DOCUMENTATION.md](DOCUMENTATION.md).

## Тесты

```bash
pip install pytest
python -m pytest -q
```

Тесты проходят весь сценарий покупателя без подключения к Telegram (API подменяется фейком).

## Стек
